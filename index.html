The open market for AI.

Independent nodes sell the models. Your request takes the best path. You pay for it in sats.

  • OpenAI-compatible

Route

Many nodes.The best inferencepath wins.

Every node publishes its own prices. Each request goes to the best one, and moves on to the next if that node is down.

See the prices

Pay

Pay per request,in sats.

No account, no card, no subscription. What you do not spend stays yours.

Lightning
Pay an invoice from any wallet.
Cashu
Paste an ecash token. It works as your API key.

Build

Plug it intoanything.

Every node speaks the OpenAI API. Change one address and your tools already work.

$ curl -fsSL \
    https://github.com/Routstr/routstrd/releases/latest/download/install.sh | sh
$ routstrd onboard
$ routstrd receive 2100  # top up over Lightning
$ routstrd clients add --claude-code  # or --opencode, --pi-agent

from openai import OpenAI

client = OpenAI(
    base_url="https://provider.example/v1",  # any Routstr node
    api_key="cashuBo2F...",  # a Cashu token is the key
)

$ curl https://provider.example/v1/chat/completions \
    -H "x-cashu: cashuBo2F..." \
    -d '{
      "model": "gpt-5-nano",
      "messages": [{"role": "user", "content": "hello"}]
    }'
