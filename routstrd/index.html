routstrd

Every model, for your agents.

A small program on your computer. It sends your agents' requests to the cheapest Routstr node and pays it in sats.

    How it picks

    • FindsNodes list themselves on Nostr. It looks again every 21 minutes.
    • PicksThe cheapest node a reviewer approved.
    • PaysFrom its own wallet. Sats left on a node come back on their own.
    • Moves onA node that fails sits out a while, longer if it keeps failing. The next one takes over.

    Install

    Three commands.

    Then use your agent as you always do.

    $ curl -fsSL \
    https://github.com/Routstr/routstrd/releases/latest/download/install.sh | sh
$ routstrd onboard --claude-code  # makes a wallet, sets up your agent
$ routstrd receive 2100  # a Lightning invoice for 2,100 sats

    Teams

    One wallet
    for the whole team.

    Run routstrd-remote on a server. Everyone gets their own key and a monthly limit in sats.

    routstrd-remote on GitHub
    $ routstrd remote https://ai.your-team.com
$ routstrd npubs whoami  # your npub
$ curl https://ai.your-team.com/npubs \
    -H 'x-routstr-bootstrap-token: TOKEN' \
    -d '{"npub": "npub1...", "name": "you"}'  # makes you the admin; TOKEN is in the server log
$ routstrd npubs add npub1... --name alice --limit-sats 50000  # 50,000 sats a month

    $ routstrd remote https://ai.your-team.com  # makes your own key
$ routstrd npubs whoami  # send this to your admin
$ routstrd clients add --claude-code  # once you are in
