Every model

The cheapest node. Then the next.

routstrd on your machine sends each request to the cheapest node you approved for that model, and to the next one if it fails.

More on routstrd

Nothing to tie it to you.

No account means no name on a request. Reach a node over Tor, or pick a sealed model that not even the node can read.

Nodes on Tor

No list anyone can shut down.

Each node announces itself on Nostr relays, and curators vouch for the ones they trust. Apps find them there, with no server in between.

The protocol

One wallet for the whole team.

Run routstrd on a server. Everyone signs in with their own Nostr key and gets their own keys; one wallet pays, and you see who spent what.

Run a node 
$ curl https://node.example.com/v1/balance/create \
    -H "Content-Type: application/json" \
    -d '{ "initial_balance_token": "cashuB..." }'

{ "api_key": "sk-...", "balance": 1000000 }  # 1,000 sats, in millisats

$ curl https://node.example.com/v1/balance/lightning/invoice \
    -H "Content-Type: application/json" \
    -d '{ "amount_sats": 1000, "purpose": "create" }'

$ curl https://node.example.com/v1/balance/lightning/invoice/ID/status  # once it is paid, the key
